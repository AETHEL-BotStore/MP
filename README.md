# Личный сайт Матвея Прокудина

Статичный сайт для GitHub Pages. Русская версия находится в `index.html`, английская — в `en/index.html`. Общие CSS и JS лежат в корне, изображения — в `assets/`. Сборка и установка зависимостей не нужны.

## Как опубликовать

1. Распакуйте архив в корень **отдельного главного репозитория личного сайта** (на одном уровне должен лежать `index.html`). Не загружайте эти файлы поверх репозитория AETHEL.
2. В настройках репозитория откройте **Settings → Pages** и выберите публикацию из ветки `main`, папка `/ (root)`.
3. Если подключите свой домен, добавьте `CNAME`, затем укажите полный адрес сайта в `canonical`, `og:url`, JSON-LD `url` и `sitemap.xml`. Сейчас эти поля намеренно не заполнены: адрес личного сайта неизвестен.

## Перед публикацией стоит добавить

- **Живые кадры о работе.** На сайте сейчас один выбранный портрет. Позже можно добавить настоящий снимок за работой над продуктом, встречу с клиентом или выступление.
- **Экран владельца AETHEL:** в карточках студий уже есть их профили и работающие боты с переключением и увеличением. Отдельно полезно показать CRM-систему и то, как владелец управляет записями.
- **Подробные кейсы и отзывы** с разрешения клиентов: задача, что было сделано, что изменилось, конкретные измеримые результаты. Карточки студий сейчас показывают, кто доверил вам свою запись; это отдельный формат.
- **Больше личного контекста:** почему вы начали строить AETHEL, что оказалось самым трудным в запуске в 19 лет, какие принципы помогают выбирать задачи, чем хотите заниматься дальше. Это хороший материал для будущей страницы «История» и блога.
